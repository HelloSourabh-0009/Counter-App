# Counter-App
A feature-rich counter application built with vanilla HTML, CSS, and JavaScript, focused on state control, UX feedback, accessibility, and persistence.  This project is not just about incrementing numbers — it’s about learning how UI reacts to state, how logic drives UX, and how small decisions compound into clean software.
✨ Features

Increment / Decrement / Reset counter

Base limit at 10, extendable to 50

Dynamic button enable/disable logic

Animated number transitions

Shake animation on limit reached

Keyboard shortcuts support

Dark / Light theme toggle with persistence

State saved using localStorage

📁 Tech Stack

HTML (structure)

CSS (layout, animations, themes)

JavaScript (state management, logic, events)

No frameworks. No libraries.
Everything is built from fundamentals.
